# Getaway Travlr
This repository was built for the CS-465 course at SNHU which shows the fundementals of full stack development. In this course we take advantage of the MEAN stack.

## What is the MEAN stack?
The MEAN stack consists of four primary technologies that provide a foundation to quickly buildout websites in a reliable manner. One major advantage of the MEAN stack is conformity. Every portion of the MEAN stack can be fully utilized with the same programming language, JavaScript.

These technologies are:
* M : MongoDB
* E : Express.js
* A : Angular JS
* N : Node.js
